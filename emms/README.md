# Enterprise Meeting Management System (EMMS)

Java backend service for iMeeting. Handles business logic, database interaction, and API endpoints.

## 🛠 Backend Tech Stack
- **Java 8** and **Spring Boot 2.1.0** for the application framework  
- **Maven** for build and dependency management  
- **MySQL** as the primary relational database, with Alibaba Druid for connection pooling  
- **Redis** for caching and session management via Spring Data Redis and Spring Session  
- **Alibaba Cloud SDKs** for SMS and object storage integration  
- JSON parsing is handled by **FastJSON**  
- Additional libraries include Apache POI for Excel file processing, ZXing and QRGen for QR code generation, BCrypt for password security, and others.
